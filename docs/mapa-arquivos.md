## APIs e dependências

A API ativa de manobras no Cloudflare é `functions/api/movimentacao-navios.js`. O arquivo homônimo em `api/` não é idêntico e foi preservado; não foi confirmado um deployment separado que o utilize. O Editor usa `/api/gemini`; o Radar usa rss2json e feeds públicos. `api/index.py` utiliza Flask, correspondendo à dependência de `requirements.txt`; esse par não foi removido.

A busca estática não resolve construções dinâmicas nem verifica links externos. A decisão de remover um arquivo exige examinar seus consumidores e, quando disponível, os acessos ao endereço publicado.
